COMPUTAÇÃO DE COMPONENTES BIDIMENSIONAIS DADA UMA DIREÇÃO THETA-RADIANA (ORIGEM)
	x = |V|*cos(thetaRadiano)
	y = |V|*sen(thetaRadiano)

COMPUTAÇÃO DE COMPONENTES BIDIMENSIONAIS UMA DIREÇÃO THETA-RADIANA (RELATIVAMENTE)
	pontoRelativo = (x1,y1)
	x = x1+|V| * cos(thetaRadiano)
	y = y1+|V| * sen(thetaRadiano)

	1. (x,y) permitem a computação da hipotenusa ou magnitude de vetor
	assim como seu ângulo em radianos ou graus(requer conversão).
	2. "pontoRelativo" pode ser um objeto cuja posição varia em função do tempo.

COMPUTAÇÃO DAS COMPONENTES PARA UMA VELOCIDADE ARBITRARIA v
	vx = v·cos(thetaRadiano)
	vy = v·cos(thetaRadiano)

	v - velocidade escalar
	(vx,vy) - componentes

	Para aceleração:
	ax = a·cos(thetaRadiano)
	ay = a·cos(thetaRadiano)

	a - aceleração escalar
	(ax,ay) - componentes


ESTRUTURA DE DADOS DE UM OBJETO 2D MÓVEL
	Posição→Velocidade→Aceleração quadrático→linear→constante
	(px, py)
	v (vx, vy) onde sqrt( vx² + vy² ) = hipotenusa = modulo do vetor velocidade
	a (ax, ay) onde sqrt( vx² + vy² ) = hipotenusa = modulo do vetor aceleração

DISTÂNCIA ENTRE DOIS PONTOS NO PLANO BIDIMENSIONAL (HIPOTENUSA)
  abs( sqrt( (x2-x1)² + (y2-y1)² ) )

	1.computar as diferenças por dimensão entre b=DESTINO RELATIVO e a=ORIGEM RELATIVA
		DeltaX = Xb - Xa
		DeltaY = Yb - Ya
	2. Aplique função atan2(y,x)
		thetaRadiano = atan2( DeltaY, DeltaX )

CONSTANTE DA GRAVITAÇÃO UNIVERSAL
	constante da gravitação universal deve ser G=1
	para estabilidade númerica computacional.

COMPUTANDO FORÇA GRAVITACIONAL
	Força gravitacional = (G · ma · mb) / distancia( a, b )

	Força é igual constante da gravitação universal vezes massa do objeto 'a'
	vezes a massa do objeto 'b' sobre a distancia entre ambos

MÉTODOS NUMÉRICOS PARA ESTABILIDADE NUMÉRICA
	deltaTempo = dt (dt menor que 1)

	EULER - método instável, porém simples ! -----

	nova_posicao = posicao_atual + ( velocidade_atual · dt )

	VERLET----------------------------------------

	Xn+1 = 2Xn - Xn-1 + a·dt²

	X próximo é igual a duas vezes o X atual menos X anterior mais
	aceleração vezes o quadrado do delta tempo.

	I. defina aceleração
	II. salve posições x,y ... atuais em temp_x, temp_y ...
	III. compute nova posição EX: px = px + ( px - old_px ) + ax * (dt*dt)
	IV. por fim, salve posições antigas EX: old_px = temp_x ..

	VERLET VELOCIDADE (complexo)-------------------

	Considere apenas a uma dimensão (neste caso x)
	Computando nova posição usando velocidade e aceleração atuais:
	x( t + dt ) = x(t) + v(t)·dt + 1/2·a(t)·dt²
	
	Velocidade de meio passo (intermediária):
	v( t + 1/2·dt )	= v(t) = 1/2·a(t)·dt

	Computar nova aceleração e velocidade final
	v( t + dt ) = v( t + 1/2·dt ) + 1/2·a( t + dt )·dt


	Em Computês:
	px = vx * dt + 0.5 * ax * (dt*dt);	//obter posição usando aceleração atual
	let v_half_x = vx + 0.5 * ax * dt;	//velocidade de meio passo
	ax = 2;															//aceleração arbitrária ou gravidade ou outra força ...
	vx = v_half_x + 0.5 * ax * dt;			//velocidade final (usando nova aceleração)

	2D----------------
	px = vx * dt + 0.5 * ax * (dt*dt);	//obter posição usando aceleração atual
	py = vy * dt + 0.5 * ay * (dt*dt);	//obter posição usando aceleração atual

	let v_half_x = vx + 0.5 * ax * dt;	//velocidade de meio passo
	let v_half_y = vy + 0.5 * ay * dt;	//velocidade de meio passo

	a -> (ax,ay)												//manipulação da aceleração

	vx = v_half_x + 0.5 * ax * dt;			//velocidade final (usando nova aceleração)
	vy = v_half_y + 0.5 * ay * dt;			//velocidade final (usando nova aceleração)
